Instructions & How to Use

  1. Cloud Sync - Go to Admin Panel and paste your Google Apps Script URL to enable automatic cloud backup to Google Sheets.
  2. Auto Save - Every entry automatically syncs to Google Sheets in the background. No manual backup needed.
  3. Multi-User Safe - If multiple users add entries, data is merged automatically so nothing is lost.
  4. Click Add New Entry - A popup form will open with auto-generated Invoice number.
  5. Auto Invoice - Invoice number is automatically generated and increments with each new entry.
  6. Auto Time & User - Every entry automatically saves the current time and the logged-in user's name.
  7. Fill the Form - Enter Date, Name, ID, Mobile, Application, Age/Code, Amount, and Request Number.
  8. Click Save Entry - The record is saved locally and synced to the cloud automatically.
  9. Search & Filter - Use the search bar to find any data by Invoice, Request No, Name, ID, or who Entered it.
  10. Sort Columns - Click any column header to sort records ascending or descending.
  11. Export - Click Export CSV to download all records.
  12. Delete - Admin only: Can delete single records or clear all. Regular users cannot delete.
